# Котик-почтальон

Сайт для свидания: этапы с вопросами для разговора, игра «Совпадём?», «Кто из нас?», пикантные вопросы и оценка прогулки. Каждый этап, кроме первого, открывается ответом на вопрос о нашей жизни. Котиков внизу можно нажимать: они разыгрывают одну из 17 сценок.

Сайт: https://fluffi123.github.io/kotik-svidanie/

## Как это работает

| Что | Как |
|---|---|
| Её ответы на вопросы-замки, итог «Совпадём?» и оценка прогулки | приходят тебе сообщениями от Telegram-бота |
| Этапы | лежат в `js/content.js`; закрытый этап открывается ответом на вопрос о вашей жизни |
| Когда она открывает этап | бот присылает вопрос и её ответ |
| Котики в хабе | по нажатию разыгрывают одну из 17 сценок (`js/scenes.js`) |
| Без бота | сайт работает, просто ответы никуда не уходят |

Открытые этапы запоминаются на её телефоне.

## Подключение Telegram-бота

Уже подключён: @kissSvidLisa_bot. Если понадобится новый бот:

1. Открой в Telegram [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай имя и username бота. BotFather пришлёт токен вида `123456789:AA...`.
2. Найди своего нового бота и нажми **Start** (или отправь ему любое сообщение). Без этого бот не сможет тебе писать.
3. Узнай свой chat id: открой в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найди в ответе `"chat":{"id": 123456789` — это число и есть chat id.
4. Впиши токен и chat id в `config.js`, затем закоммить и запушь. Через минуту GitHub Pages обновится.

Токен будет виден в коде сайта. Худшее, что с ним можно сделать, — слать тебе спам от этого бота. Если такое случится, отзови токен у @BotFather командой `/revoke` и впиши новый.

## Вопросы, которые открывают этапы

Каждый закрытый этап открывается, когда она отвечает на вопрос о вашей совместной жизни. Вопросы и ответы лежат в `js/content.js`, в поле `unlock` у каждого этапа:

```js
unlock: { q: "Где было наше первое свидание?", answers: ["горьк", "нескучн"] },
```

- В `answers` можно написать несколько вариантов и даже часть слова: ответ засчитывается, если он **содержит** любой из вариантов. Регистр, пробелы, знаки препинания и «ё» не важны. Например, `"горьк"` подойдёт к «в парке Горького».
- Пока `answers` пустой, засчитывается любой ответ. Не забудь вписать свои.
- Когда она открывает этап, бот присылает тебе вопрос и её ответ.
- Ответы видны в коде сайта, так что это игра, а не защита.

## Свои этапы

- **match** — «Совпадём?»: она отвечает, передаёт телефон тебе, ты отвечаешь, и сайт показывает, совпали ли вы. Правильных ответов нет, итог приходит в бот.
- **quiz** — вопросы с вариантами; `correct` — номер правильного варианта, считая с нуля, или `null`, если правильного ответа нет.
- **deck** — колода карточек с вопросами, ничего не отправляет.
- **form** — анкета с полями `hearts` (оценка сердечками) и `text`.

Чтобы добавить этап, добавь в `STAGES` ещё один объект с новым `id`. Порядок в списке = порядок на сайте.

## Проверить локально

```bash
python -m http.server 8000
```

Потом открой http://localhost:8000. Двойной клик по `index.html` не сработает: модули JavaScript работают только через сервер.
