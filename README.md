# Котик-почтальон

Интерактивное приглашение на прогулку: стираемая карточка, котик приносит бумагу для письма, она пишет пожелания, котик уносит конверт (и падает по дороге). Дальше сайт превращается в хаб этапов для самого свидания: вопросы для разговора, тест, «Кто из нас?», пикантные вопросы и оценка прогулки.

Сайт: https://fluffi123.github.io/kotik-svidanie/

## Как это работает

| Что | Как |
|---|---|
| Её письмо, результаты теста и оценка прогулки | приходят тебе сообщениями от Telegram-бота |
| Этапы | лежат в `js/content.js`; закрытый этап открывается секретным словом, которое ты ей говоришь |
| Когда она открывает этап | бот присылает «Она открыла этап …» |
| Без бота | сайт работает, а в конце письма у неё появляется кнопка «Скопировать» |

Если она уже отправила письмо, при следующем открытии сайта она сразу попадает в хаб этапов. Приглашение можно посмотреть заново по ссылке внизу хаба или по адресу `…/#invite`.

## Подключение Telegram-бота (около 3 минут)

1. Открой в Telegram [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай имя и username бота. BotFather пришлёт токен вида `123456789:AA...`.
2. Найди своего нового бота и нажми **Start** (или отправь ему любое сообщение). Без этого бот не сможет тебе писать.
3. Узнай свой chat id: открой в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates`
   и найди в ответе `"chat":{"id": 123456789` — это число и есть chat id.
4. Впиши токен и chat id в `config.js`, затем закоммить и запушь. Через минуту GitHub Pages обновится.

Токен будет виден в коде сайта. Худшее, что с ним можно сделать, — слать тебе спам от этого бота. Если такое случится, отзови токен у @BotFather командой `/revoke` и впиши новый.

## Секретные слова

Слова задаются в `js/content.js`, в поле `word` у каждого этапа. Сейчас там такие:

| Этап | Слово |
|---|---|
| Вопросы для разговора | открыт сразу |
| Угадай, что я выбрал | мурмур |
| Кто из нас? | кто тут |
| Пикантные вопросы | огонёк |
| Оценка прогулки | спасибо |

Регистр, пробелы и буква «ё» при вводе не важны. Слова видны в коде сайта, так что это игра, а не защита.

## Свои этапы

- **quiz** — вопросы с вариантами; `correct` — номер правильного варианта, считая с нуля, или `null`, если правильного ответа нет. Перед свиданием поправь правильные ответы под себя: сейчас везде стоит первый вариант.
- **deck** — колода карточек с вопросами, ничего не отправляет.
- **form** — анкета с полями `hearts` (оценка сердечками) и `text`.

Чтобы добавить этап, добавь в `STAGES` ещё один объект с новым `id`. Порядок в списке = порядок на сайте.

## Проверить локально

```bash
python -m http.server 8000
```

Потом открой http://localhost:8000. Двойной клик по `index.html` не сработает: модули JavaScript работают только через сервер.
