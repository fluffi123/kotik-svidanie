# Котик-почтальон

Интерактивное приглашение на прогулку: стираемая карточка, котик приносит бумагу для письма, она пишет пожелания, котик уносит конверт (и падает по дороге). Дальше сайт превращается в хаб этапов для самого свидания: тест, вопросы для разговора, оценка прогулки.

- `index.html` — сайт для неё.
- `admin.html` — твой пульт: её ответы и включение этапов.

## Как это работает

| Что | Где |
|---|---|
| Её письмо, результаты теста и анкет | сохраняются в Firebase Firestore, ты читаешь их в `admin.html` |
| Этапы | `js/content.js`; ты открываешь их в `admin.html`, и они сразу появляются у неё |
| Без Firebase | сайт работает, этапы открыты сразу, письмо можно скопировать и прислать вручную |

Если она уже отправила письмо, при следующем открытии сайта она сразу попадает в хаб этапов. Посмотреть приглашение заново можно по ссылке внизу хаба или по адресу `…/#invite`.

## Подключение Firebase (один раз, около 10 минут)

1. Зайди на https://console.firebase.google.com, нажми **Create a project**, Google Analytics можно выключить.
2. **Build → Firestore Database → Create database**. Регион любой европейский (например, `eur3`), режим **production**.
3. Там же открой вкладку **Rules**, вставь содержимое файла `firestore.rules`, замени `ТВОЯ_ПОЧТА@example.com` на свою почту и нажми **Publish**.
4. **Build → Authentication → Get started → Sign-in method → Email/Password → Enable**.
   Потом **Users → Add user**: твоя почта и пароль. С ними ты входишь в `admin.html`.
5. **Project settings** (шестерёнка) **→ Your apps → значок `</>`** (Web), придумай имя и зарегистрируй приложение. Скопируй объект `firebaseConfig`.
6. В `config.js` замени `null` на этот объект, а в `ADMIN_EMAIL` впиши ту же почту:

   ```js
   export const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   export const ADMIN_EMAIL = "you@example.com";
   ```

   `apiKey` из Firebase не секрет: доступ защищают правила из шага 3.
7. Закоммить и запушь, через минуту GitHub Pages обновится.

## Свои этапы

Всё содержимое лежит в `js/content.js`:

- **quiz** — вопросы с вариантами; `correct` — номер правильного варианта, считая с нуля, или `null`, если правильного ответа нет. Обязательно замени вопросы-заготовки на свои.
- **deck** — колода вопросов для разговора, ничего не отправляет.
- **form** — анкета с полями `hearts` (оценка сердечками) и `text`.

Чтобы добавить этап, добавь в `STAGES` ещё один объект с новым `id`. Порядок в списке = порядок на сайте. `open: true` делает этап открытым сразу.

## Проверить локально

```bash
python -m http.server 8000
```

Потом открой http://localhost:8000. Просто открыть `index.html` двойным кликом не получится: модули JavaScript работают только через сервер.
